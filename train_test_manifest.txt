TRAINING AND TEST PROCESSED-IMAGE MANIFEST
Manifest version: 1.0

1. SCOPE AND PROVENANCE

This file lists the processed MRI filenames in the training and test directories used by the current hybrid-supervised implementation. The data composition follows SIRNet [1]. Directory membership was checked against the available input files. The training-pair membership was also checked against the available three-stage training logs.The earlier registration papers [2,3] provide methodological context. Their LPBA40, OASIS3, HBN, and liver CT experiments are outside this study. Their OASIS splits are not assumed to identify the images used in this study. The present image counts follow SIRNet [1].

IMPORTANT IDENTITY LIMITATION:
BraTS20_Training_*, BraTS20_Test_*, OASIS1_train_*, and OASIS1_test_* are processed-image aliases. Their correspondence to original public dataset participant and scan/session identifiers is not available in this manifest. A suffix number is an alias, not a verified source participant identifier.

The participant-image column counts image entries, not verified unique participants. BraTS-Reg contributes 140 longitudinal pairs, comprising 280 image entries. It is used only for evaluation in this study.

Modality: T1-weighted MRI, as reported in SIRNet [1] and the current manuscript. The BraTS-Reg stored filenames explicitly retain the T1 suffix; BraTS2020/OASIS-1 aliases do not retain the original modality suffix. The original-file mapping remains needed for source-level verification.

Preprocessing reported in SIRNet [1]: FSL affine alignment to MNI space at 1-mm isotropic resolution, min-max intensity normalization, and cropping to 160 x 224 x 192 voxels.

7. INTER-SUBJECT TEST PAIR DEFINITION

Fixed pool: all 50 filenames in Section 5.3.
Moving pool: all 50 filenames in Section 5.4.
Pair membership: the complete Cartesian product of these two pools.
Total: 50 x 50 = 2,500 distinct fixed/moving filename pairs.

For a deterministic enumeration, let F[1..50] and M[1..50] be the display-order lists in Sections 5.3 and 5.4. For every i = 1..50 and j = 1..50, define pair_number = 50*(i-1)+j, fixed = F[i], moving = M[j]. This rule fully specifies all 2,500 pairs without listing the same filenames repeatedly.

The same test images occur in multiple pairs; 2,500 registration pairs are not 2,500 independent patient observations. Pair enumeration here does not assert the historical evaluation execution order.
